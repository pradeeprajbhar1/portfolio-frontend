## 🌟 Key Features

* **Responsive Design:** Dark mode styled, modern & modern grid interface.
* **Interactive Hero:** Download Resume button, live project navigation, social link badges.
* **Skills Showcase:** Organized layout highlighting Frontend, Backend, Database, and Analytics toolstacks.
* **Featured Projects:** Showcases live applications like **IPL Analysis Dashboard**, **PhonePe Analytics**, and **E-Commerce Web Application**.
* **Certifications:** Displays verified job simulations & course certificates from **Deloitte**, **Skyscanner**, and **Apna College**.
* **Contact Integration:** Easy-to-use form to drop direct messages.
